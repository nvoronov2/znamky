# Známky

PWA для iPhone: фото почтовой марки → распознавание, состояние, оценка в CZK (диапазон), описание, аукционная история. Коллекция хранится локально (IndexedDB). Без бэкенда и без сборки. Все файлы лежат в корне репозитория.

## Возможности

- Съёмка или выбор фото, распознавание через Gemini, правка любых полей, цена по состоянию (** / * / raženo / na obálce / s vadami).
- **Hromadné nahrání**: выбираешь много фото сразу, они обрабатываются по одному и сразу сохраняются в сбирку. При лимите (429) приложение ждёт и повторяет. Неверный ключ или переполнение хранилища останавливают пакет, остальные фото остаются в очереди («Zkusit znovu»). Записи с низкой уверенностью помечены «zkontrolovat».
- **Aukční historie** в каждой карточке: поисковая строка (её предлагает модель, можно править) и ссылки на eBay (проданные лоты), Burda Auction, StampAuctionNetwork, Philasearch, Delcampe, Heritage и Google. Кнопка «Najít prodeje (AI)» ищет через Google Search и показывает найденные продажи со ссылками на источники. **Ответ ИИ нужно проверять в источнике**: модель сама истории продаж не знает. Собственные записи («+ Prodej»: аукционный дом, дата, цена) дают медиану, она попадает в CSV.
- Поиск по сбирке (без учёта диакритики, по стране, мотиву, номиналу, номеру каталога) и сортировка.
- Záloha: полный бэкап в JSON (с фото) через меню «Поделиться» и восстановление. Это защита от очистки памяти Safari.
- Экспорт CSV с разделителем `;`.
- Офлайн-режим: «Vložit JSON» (копируешь промпт, вставляешь ответ любой модели).

## Ключ API

Ключ Gemini лежит в localStorage браузера и **публичен для любого, кто откроет приложение**. Ограничь его по HTTP-referrer адресом `USER.github.io`. Для чужих пользователей используй режим «proxy» (`worker.js`, Cloudflare Worker): ключ остаётся у воркера, клиент его не отправляет.

## Деплой (с телефона)

1. Создать публичный репозиторий в Safari, загрузить **все файлы из архива** (Add file → Upload files, папок нет).
2. Settings → Pages → Deploy from a branch → `main` / (root) → Save.
3. Открыть `https://USER.github.io/REPO/`, затем Safari → Sdílet → Přidat na plochu.

При обновлении файлов увеличь номер версии `CACHE` в `sw.js`, иначе телефон покажет старую версию. После обновления закрой и открой приложение дважды.

Локально: `npx serve .`

## Структура

`index.html`, `styles.css`, `manifest.webmanifest`, `sw.js`, иконки, `worker.js` (опциональный прокси), модули `main.js`, `state.js`, `db.js`, `api.js`, `schema.js`, `price.js`, `image.js`, `i18n.js`, `dom.js`, `csv.js`, `backup.js`, `auctions.js` и экраны `ui-*.js`. Каждый JS-файл ≤ 8 КБ.

## Отличия от исходного ТЗ

- Модели: `gemini-flash-latest` (по умолчанию), `gemini-flash-lite-latest`, `gemini-2.5-flash`.
- В записи есть `image` (1400px) рядом с `thumb`; новые поля `auctionQuery`, `comps`, `salesNote`, `salesSources`.
- Недостающие оценки считаются множителями от `used`; нет `used` или блока `estimates` → нули. Ошибки: `Error.message` = ключ из `T`, `detail` добавляет HTTP-статус и текст API.
